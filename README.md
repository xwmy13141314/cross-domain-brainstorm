# 跨域迁移脑暴

一个用于 **产品创新 / 功能创新 / 交互创新 / 服务模式创新** 的 Claude Skill。

核心方法不是行业内横向借鉴，而是通过 **跨域机制迁移** 打破惯性：

- 锁定问题
- 抽取跨域领域
- 提炼底层机制
- 强制嫁接
- 快速收敛

它适合在以下场景中使用：

- brainstorm / 头脑风暴卡住
- 现有方案过于同质化
- 想从其他行业借机制，而不是抄功能
- 团队共创时需要快速打开思路

它不适合用于：

- 行业研究 / 竞品研究
- 根因分析 / 复盘
- PRD 定稿
- 文章写作

## 技能定位

`跨域迁移脑暴` 是一个 **创意生成器**，不是研究工具，也不是写作工具。

目标不是先分析清楚，而是先炸出一批有突破感的候选创意，再筛出最值得推进的方向。

## 核心原则

- 迁移 **底层机制**，不要照搬 **表面功能**
- 发散阶段不提前否定
- 收敛阶段再引入理性判断
- 先追求候选数量和多样性，再追求最优解
- 如果结果只是“把别人的界面 / 按钮 / 玩法搬过来”，判定为低质量创意

## 适用场景示例

- “帮我跨界脑暴一下这个功能”
- “帮我用别的行业机制想新方案”
- “当前脑暴卡住了，帮我炸点新想法”
- “想做一些不那么像同行的产品创意”

## 文件说明

- `SKILL.md`
  - 技能主体
  - 定义触发条件、边界、最小工作流、默认输出格式

- `references/domain-library.md`
  - 跨域领域库
  - 包含传统行业、AI / 数字领域、服务 / 流程领域的抽样建议

- `references/mechanism-examples.md`
  - 机制提炼方法
  - 高质量迁移 vs 低质量迁移示例

- `references/output-templates.md`
  - 创意池模式、Top 3 模式、单人模式、团队主持模式输出模板

- `references/example-session.md`
  - 一套完整示例演练
  - 用于校准技能输出风格和深度

## 默认工作流

1. 锁定目标对象和单一核心痛点
2. 抽取 3 个异质领域
3. 提炼每个领域的底层机制
4. 将机制强制嫁接到目标对象上
5. 发散出创意池
6. 快速收敛出 Top 3 和验证建议

## 适合搭配的其他 Skill

- `hv-analysis`
  - 当需要深度研究、竞品分析、行业分析时使用
- `product-thinking`
  - 当需要判断方向、分析产品机会时使用
- `khazix-writer`
  - 当需要把创意写成文章或长文时使用

## 安装后建议

安装后优先用两个真实案例试跑：

1. AI 产品
   - 例如：AI 笔记 APP、AI 写作工具、AI Agent 工具
2. 非 AI 场景
   - 例如：智能手表、家电、线下服务流程

这样最容易验证这个 Skill 是否真的在“迁机制”，而不是在“抄功能”。
