# 输出模板 v0.4

这份文档用于统一 `跨域迁移脑暴` 的输出。

四种用法：

- **灵感 Quick**：2-3 页，12-15 组碰撞，Top-3 落地卡（创意题默认）
- **灵感 Deep**：40-60 组碰撞 + Top-3 落地卡
- **决策 Quick**：2 页，8 个候选，3 张落地卡
- **决策 Deep**：4 页，15-18 个候选，评分/利益相关者/pre-mortem

先给结论，再给过程。不要把思考过程写成流水账。

---

**灵感模式写作规则**：

- Stage A 里零禁词（成本/BOM/可行性/风险/认证/但是/很难/不现实）。
- 爽点写成用户拿到手那一刻的具体感受，不写"提升体验"。
- 每组必须能追到一张牌；redundancy test 不过的点子不算牌产出。
- Gate 只报编号，不排序不推荐；筛选房不补刀未挑中的。
- 用户否过的类型要回灌成过滤器（写进软偏好），下一批累计编号。

### 第 1 页：执行者能照做的一页

在完整输出前，先写一个“明早能照做”的版本：

```text

```

这一页不是给评委看的，是给执行者看的。写不出来，说明落地卡还没落地。

## 六、红队卡模板

```text
创意：
1. 伦理：价值创造/提取；操纵/成瘾；隐私；歧视；安全；自主性；权力
2. 现状替代：今天怎么做；为什么换；切换成本
3. 验证者：谁验证；是否独立；每天能验几次；失败谁承担
4. 二阶效应：Goodhart；焦虑/依赖；成本转移；系统脆弱性
5. 可逆性：回滚；数据；kill switch
6. 判定：绿灯/黄灯/红灯；缓解；是否进入组合
```

## 八、写作规则

- 先给结论，再给理由。
- 每个创意一句话说清“借了什么机制、改变了什么行为、预期什么结果”。
- 不要用“赋能”“闭环”“抓手”“生态”这类空词；用具体动作和信号。
- 不确定的判断标 H/M/L；成本未知写“未知 + 区间”，不要编精确数。
- 不要把所有候选都写成“很有潜力”；要明确淘汰。
- 不要用分数掩盖判断；分数只做辅助。
- 先例三查没有工具就写“未查”，不要编造。
- 灵感 Quick 不超过 3 页；决策 Quick 不超过 2 页；Deep 不超过 4 页。
