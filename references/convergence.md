# 收敛与组合决策 v0.3

这份文档用于 `跨域迁移脑暴` 的 Step 5。

目标不是“给所有点子打分，选最高分”，而是：

> 先淘汰表面迁移和平庸方案，再选一个**风险组合**，让每个下注都带一张能落地的卡和一个便宜的可证伪实验。

## 一、先做反平庸三问

在打分之前，先问三个问题：

1. **今天具体怎么做？** 工具/人/流程/SOP/土办法，越具体越好。
2. **它做不到什么？** 成本、覆盖、信任、速度、风险，至少一个可观察证据。
3. **新方案多花什么、少花什么？** 钱、时间、人力、学习成本、风险。

三问答不出来，或答案只是“更智能/更好用/更专业”，淘汰或重抽。

为什么不用“现有产品一句话覆盖”做唯一标准：

- 农业、养老、餐饮很多题没有“产品”，只有做法和 SOP；
- 现有 SOP 可能一句话覆盖，但结构可以完全不同；
- “没人做过”不等于“没有产品”，可能只是没有人在这个场景这样做。

反平庸不是追求“怪”，而是拒绝“把已有做法换个说法”。

## 二、四道门槛（8 个候选）

每个候选先过门槛，不做总分排序。

| 门槛 | 问题 | 不过时 |
|---|---|---|
| 1. 机制保真 | 是结构迁移，还是表面换皮？ | 回到 `grafting.md` 的映射表 |
| 2. 问题匹配 | 真的解决框定的用户/结果，且不违反硬约束？ | 淘汰或改造 |
| 3. 可测试 | 能写出可证伪假设和便宜实验？ | 标“不可测试”，不进组合 |
| 4. 伦理 | 不依赖操纵、成瘾、隐私侵犯、歧视、锁定？ | kill 或 redesign |

门槛是 0/1，不是分数。过不了就是过不了。

## 三、两个 Pass/Fail 门（只对 3 个决赛 bet）

四道门槛过完，选出 3 个决赛 bet；再对它们过两个门。**不要对 8 个发散创意逐个算成本**。

| 门 | 问题 | 数据来源 | 不过时 |
|---|---|---|---|
| 成本 fit | 一次性/单次/每月成本的下限 ≤ 预算上限？ | 报价、工时、耗材、外包价 | 先缩范围一次，再 kill |
| 容量 fit | 执行人分钟/验证者次数 ≤ 可用时间/容量？ | 现有 routine、站长/护士/店长工时 | 先缩范围一次，再 kill |

规则：

- **未知可标。** 成本/容量未知时，写区间 + 假设 + 需要谁确认；不要填精确假数。
- **先缩范围一次。** 缩户数/缩频次/换买单人/换嵌入点/减一项能力；缩完仍超，再 kill。
- **Wildcard 用探针成本。** 不超过预算上限的 1/10 或 1 天人工；不要求规模成本。
- **不要用成本门把“贵但值得验证”的创意一刀切。** 先问“能不能用 1/10 版验证核心假设”。

## 四、组合，而不是 Top 3

过门槛后，选一个组合：

| 类型 | 目标 | 风险 | 证据 |
|---|---|---|---|
| **Safe bet** | 保底、快速验证、能买账 | 低-中 | 高置信 |
| **Bold bet** | 高 novelty、中高不确定性、有一个关键实验 | 中-高 | 中置信 |
| **Wildcard** | 高 novelty、高不确定性、极便宜探针 | 高 | 低置信 |

为什么不是 Top 3：

- 按总分选，容易选出三个“可行、好懂、相似”的方案；
- 组合能覆盖不同的不确定性；
- 决策者可以看到“保底/进攻/探索”的配置，而不是一个假精确的排名。

如果只能做一个，选 Safe bet；如果资源允许，至少跑 Bold bet 的关键实验；Wildcard 只在探针足够便宜时做。

## 五、三张落地卡（每张 7 行）

每个决赛 bet 写一张；填不满的不得进入组合。

```text
1. 现有替代：今天具体怎么做（工具/人/流程/SOP）
2. 它做不到什么：一句话，带可观察证据
3. 机制 + 失效前提：借了什么因果回路；若＿不成立，退化为＿
4. 最便宜测试：一周/一店/一站/一次，多少钱/多少人/多少分钟
5. 规模成本区间 + 未知项：不要精确假数；写清哪些是未知
6. 谁买单 / 谁执行 / 嵌哪一步：角色 + 现有 routine 的具体节点
7. Kill 条件 + 停止信号：出现什么数据/信号就停；谁有权停
```

### 好卡 vs 坏卡

| 坏卡 | 好卡 |
|---|---|
| “提升效率” | “店长每天班前会多花 3 分钟，把新品要点贴到现有 checklist 第 2 项” |
| “用户会喜欢” | “10 个高风险户里至少 6 户在 30 天内完成一次证据包，护理员每次 ≤3 分钟” |
| “成本更低” | “一次性印刷 300 元；每月耗材 80 元；人工增量 0.5 人时/店/周（未知：督导是否愿意） ” |
| “先做个小程序” | “第一周先用纸质卡 + 微信群，验证执行率后再决定要不要工具” |

## 六、先例三查（Quick 必做，可写未查）

每个决赛 bet 查三项：

| 查什么 | 怎么查 | 写什么 |
|---|---|---|
| 竞品/同类 | 目标行业现有产品/服务/SOP | 名称 + 它做到什么 + 它没做到什么 |
| 公开案例 | 报道、论文、政府/行业报告、社区帖子 | 来源 + 日期 + 一句结论 |
| 平台功能/专利 | 应用商店/平台更新日志/专利检索 | 功能/专利号 + 日期 + 是否覆盖 |

每次写清：

- **检索范围**：哪个平台/数据库/关键词；
- **检索日期**：YYYY-MM-DD；
- **证据等级**：强（可复现/官方）/ 中（可信报道/案例）/ 弱（单一帖子/未核实）/ 未查。

没有检索工具时，三项都写“未查”，置信度标 L；**禁止编造先例、专利号、日期**。如果查到直接先例，必须说明差异（场景/结构/成本/验证方式），否则 kill 或重抽。

## 七、按“最便宜证伪”排序

不要按“总分”排序，按“证伪成本”排序：

1. 先做最便宜、最能杀死创意的实验。
2. 如果实验通过，再投入更贵的验证。
3. 如果实验失败，快速 kill，不追加沉没成本。

### 证伪成本阶梯

| 成本 | 方法 | 适合验证 |
|---|---|---|
| 极低 | 5 个用户/执行者访谈 + 概念卡 | 问题是否存在、是否听得懂 |
| 低 | 落地页/假按钮/邮件测试/纸质卡 | 兴趣/点击/预约/执行意愿 |
| 中 | Wizard-of-Oz / 人工模拟 / 单店试点 | 价值是否成立、是否愿意用 |
| 中高 | 单点原型 / 灰度 / 一个小站 | 行为改变、留存、效率 |
| 高 | 完整产品/全量推广 | 规模化、商业模型 |

### 实验周期模板

- **短周期（1-7 天）**：执行率、完成率、误报率、理解度；适合运营题的第一周试点。
- **长周期（2-12 周）**：留存、复发率、病害/质量结果、季节性；适合农业、健康、订阅。

每个实验写一句：**“本实验不能验证什么”**。例如“一周试点能验证执行率，不能验证整季抗性”。

## 八、现状替代比较

每个决赛 bet 必须回答：

- 今天具体怎么做（工具/人/流程/SOP）？
- 为什么愿意换？
- 切换成本是什么（学习、迁移、社交、习惯、预算）？
- 如果不做，会怎样？
- 它比现状好在哪里？用可观察的信号说，不要用“更智能”。

如果答案是“现在也还行”，优先级要降；如果答案是“现在也能做，但成本/风险更高”，写清差多少。

## 九、可选评分（只做辅助）

如果团队需要排序，用 1-5 分，并写锚点；不要用 0-2 分制造“精确”的错觉。

| 维度 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| 机制保真 | 表面换皮 | 结构基本对应 | 结构 + 验证/激励都成立 |
| 问题匹配 | 不解决核心问题 | 部分解决 | 直接作用于框定结果 |
| 新颖性 | 现有做法常见 | 有变化但可预期 | 非显然，且能说清差异 |
| 可测试 | 无法验证 | 有方向无实验 | 假设 + 便宜实验 + 阈值 |
| 伦理 | 有操纵/伤害风险 | 有风险未处理 | 风险已识别/缓解 |

**不要**把“技术可行性”和“用户接受度”放进总分：它们容易把组合拉向保守。可行性用两个 Pass/Fail 门；接受度当实验问题。

## 十一、常见偏差

| 偏差 | 表现 | 修法 |
|---|---|---|
| 可行性偏见 | 先淘汰“难做”的，留下渐进式 | 发散阶段禁用可行性词；可行性只做门 |
| 分数膨胀 | 所有创意 4-5 分 | 写锚点；先门槛，后评分 |
| 熟悉偏好 | 选“像我们本来就要做的” | 反平庸三问；wildcard |
| 新颖偏好 | 选“最怪”的，不管有用 | 问题匹配门槛；便宜实验 |
| 群体压力 | 老板喜欢的进组合 | 先 silent writing，再 dot voting |
| 沉没成本 | 实验失败还继续 | 预先写 kill 条件 |
| 成本假精确 | 把未知成本写成精确数 | 写区间 + 未知 + 谁确认 |
| 成本一刀切 | 算不清就 kill | 先缩范围一次；wildcard 用探针成本 |

## 十二、收敛检查清单

- [ ] 反平庸三问做了吗？
- [ ] 四道门槛都过了吗？
- [ ] 三个数 + 否决者写了吗？未知项标了吗？
- [ ] 只对 3 个决赛 bet 做了成本/容量门吗？
- [ ] 超限时先缩范围一次，再 kill 了吗？
- [ ] 组合里有 safe / bold / wildcard 吗？
- [ ] 三张落地卡各 7 行吗？
- [ ] 先例三查写了吗？检索范围/日期/证据等级有吗？
- [ ] 假设是否包含对象、动作、信号、阈值、时间窗？
- [ ] 是否按证伪成本排序？
- [ ] 是否回答了“今天具体怎么做、为什么换”？
- [ ] 是否把可行性误当成了“好”？
- [ ] 是否写了“本实验不能验证什么”？
