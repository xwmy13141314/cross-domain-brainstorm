# 跨域领域库 v0.3

这份领域库用于 `跨域迁移脑暴` 的 Step 2。

它不是“行业清单”，而是一副**结构牌堆**：目标不是找相似行业，而是找**结构不同、但能桥接**的领域。

## 一、先标目标坐标

### 结构三轴（必选）

| 轴 | 取值 | 你要回答 |
|---|---|---|
| 集中度 | 集中 / 分散 / 网络化 | 决策权、规则、资源由谁掌握？ |
| 同步性 | 实时 / 批量 / 长周期 / 偶发 | 反馈和动作的时间尺度是什么？ |
| 仲裁/验证 | 外部可验证 / 自我报告 / 无仲裁 | 谁说“这件事成了/没成”？ |

### 情境四轴（按需）

| 轴 | 取值 |
|---|---|
| 载体 | 物理 / 数字 / 社会 / 生物 / 制度 |
| 主体 | 个人 / 团队 / 群体 / 算法 / 混合 |
| 风险 | 低 / 中 / 高 / 不可逆 |
| 资源 | 充足 / 稀缺 / 波动 |

- **Quick**：选 3 个最关键的轴（至少 1 个结构轴）。
- **Deep**：7 轴全标。

## 二、抽样算法

1. **写目标坐标**：例如“数字·分散·偶发·低风险·资源充足·自评·个人”。
2. **筛距离**：源领域与目标至少 **3 个轴不同**，其中至少 **1 个结构轴**不同。
3. **找桥**：写一句“两者都在＿＿结构下，解决＿＿相似问题”。桥必须涉及因果结构，不是“都属于服务业”。
4. **看丰富度**：这个领域有没有清晰的触发、反馈、失效前提？标 H/M/L。
5. **选组合**：
   - Quick：2 个高距离 + 1 个 wildcard。
   - Deep：3 个高距离 + 1 个 wildcard + 1 个 anti-domain（目标默认做法的反面）。
6. **用户指定领域**最多占 1 个；必须另有 1 个结构异质 + 1 个 wildcard。
7. **排除直接同类/竞品**；如果只能选同类，说明“只借哪个机制、不借什么”。
8. **标置信度**：高风险/不熟悉领域标 L，先核实再用。

### 五个标签（抽牌前先看）

| 标签 | 取值 | 用途 |
|---|---|---|
| 资源等级 | 足 / 稀 / 波 | 低资源目标至少抽 1 张“稀/波”牌 |
| 权力距离 | 平 / 层级 / 混合 | 判断机制是否需要“有人能拍板/能强制” |
| 观察方向 | 自评 / 他评 / 无 | 判断反馈信号是否独立 |
| 验证者容量 | 高 / 中 / 低 | 判断机制会不会把验证者压垮 |
| 示例占用 | 是 / 否 | 避免每次都抽到示例用过的牌 |

### 三条硬规则

1. **低资源目标至少 1 张低资源/非正规经济牌。** 目标资源=稀缺/波动时，不能全抽“资源充足”的机构牌。
2. **与示例重合 ≤1 张。** 示例牌：急诊分诊、审计、免疫系统、航空检查单、医院交接班、修道院日课；wildcard 不复用示例。
3. **目标行业自身的牌不得抽。** 做餐饮不抽餐厅后厨，做养老不抽殡葬；这是“排除同类”的一部分。

### 什么叫“结构桥”

好桥：

- “两者都在**资源稀缺、信息不完整**的情况下分配注意力。”（急诊分诊 → 笔记复用）
- “两者都需要**在责任转移时防止上下文丢失**。”（护士交接 → 团队笔记交接）
- “两者都靠**独立复核**防止单点错误。”（航空检查单 → 高风险家用设备）

坏桥：

- “都属于服务业。”
- “都需要用户体验。”
- “都可以用 AI 重做一遍。”

坏桥只有标签相似，没有因果结构相似。

| 食品召回 | 集中·偶发·外验 | 制度·团队 | 高·稀缺 | 稀/层级/他评/高/否 | 批次追溯；分级召回；通知 | 缺陷产品的溯源与撤回 |
| 产地收购分级 | 分散·偶发·外验 | 物理·团队 | 中·稀缺 | 稀/层级/他评/中/否 | 分级；定价；扣杂 | 质量不确定下的分级定价 |

### 新增牌使用说明

- 低资源目标至少抽 1 张；目标资源=足时也可抽 1 张作对照。
- 农业/食品牌优先用于长周期、外部验证、批次追溯题；不要拿“屠宰检疫”直接套“食品召回”，两者结构不同。
- 标签只是提示，不是免检；新增牌同样要过 5 个表面复制测试和失效前提。

## 四、好领域的三个标准

1. **结构距离**：至少 3 轴不同，含 1 个结构轴。
2. **可桥接**：能写出一句涉及因果结构的桥，而不是标签相似。
3. **机制丰富**：有清晰的触发、反馈、失效前提；不是只有“氛围”或“美学”。

如果一个领域“很酷但说不清机制”，标 L，换掉。

## 五、避免的抽样

- 做 AI 笔记，抽“其他笔记软件” → 同行借鉴。
- 做外卖，抽“团购平台” → 同一结构。
- 做智能手表，抽“其他穿戴设备” → 同一载体。
- 抽“游戏/快递/AI 绘画”只因为它们常见 → 示例锚定，不是结构选择。
- 做养老，抽“殡葬服务” → 目标行业相邻，不是结构选择。
- 做餐饮，抽“餐厅后厨” → 目标行业自身，属于同类借鉴。
- 做 AI 笔记，抽“急诊分诊/审计/免疫系统”三张 → 示例占用超过 1 张。

如果抽到同类：

- 换一个结构轴不同的领域；
- 或者明确“只借哪个机制、不借什么”；
- 或者用 anti-domain：目标默认做法的反面。

## 七、没有合适牌时

自己造一个领域坐标：

1. 选一个和目标结构不同的真实场景（越具体越好）。
2. 标 7 轴。
3. 写 2 个机制候选。
4. 写失效前提。
5. 如果写不出，换场景。

领域库是起点，不是边界。
