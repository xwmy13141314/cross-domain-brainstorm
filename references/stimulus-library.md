# 品类刺激库（Stimulus Deck）v0.4

> 灵感模式（碰撞房）专用。100 张远距离品类牌 / 11 个世界。
>
> 设计原则：**品类距离最大化**——按"货架世界"分池，每个世界和题面产品隔着一堵墙（三防手机不在任何一池里，但抽牌时仍须避开与题面气质过近的世界）。
>
> 每张牌：品类名 [具象/抽象] + 2-3 个物理/机制属性 + 一句话核心机制 + 代表物件。碰撞时用属性去 force-fit，不是照抄物件。

## 抽样硬规则（碰撞房 §2）

1. Quick 抽 12-15 张，Deep 抽 40-60 张
2. ≥5 个不同世界；同世界两张不相邻
3. ≥2 张具象 + ≥1 张抽象（每张标 [具象]/[抽象]）
4. 与题面产品气质过近的世界减半抽（如"军品战场"之于三防机——都硬核风，只允许 1-2 张破簇）
5. 同一会话不重复抽同一张
